# D-005 — Editor cancel model differs (Monday retains edits, Pipeline discards)

**Category:** Functional / State transition
**Related states:** S07 (editor modified, unsaved), S09 (editor cancelled)
**Related test cases:** TC-036

## Summary
Monday's label editor retains unapplied edits when the editor is closed (Escape) — the rename commits without an explicit Apply. Pipeline documents and implements the opposite model: "Escape discards unapplied edits."

## Monday behaviour
Renaming L02 to L02X in the editor and pressing Escape (without Apply) retains the edit; the dropdown and saved values reflect the rename after reopening.

## Pipeline behaviour
The editor helper text states "Existing label colors save immediately. Apply saves other edits; Escape discards unapplied edits." The duplicate-rename test confirmed the draft (renamed value) was discarded by Escape, restoring the previous label name.

## Reproduction steps
1. Open Edit Labels.
2. Rename a label without clicking Apply.
3. Press Escape to close the editor.
4. Reopen the editor and inspect the label name.

## Expected result (Monday reference)
The unapplied rename is retained after Escape (edits persist without Apply).

## Actual Pipeline result
The unapplied rename is discarded by Escape.

Monday's model is unusual (no explicit discard). Pipeline follows the conventional explicit-commit model. Colour-only edits save immediately in Pipeline (per helper text), which matches Monday's immediate colour-save model.
