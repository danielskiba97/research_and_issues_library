# D-003 — Duplicate label names accepted on Monday, blocked on Pipeline

**Category:** Functional / Validation
**Related states:** S14 (validation/error)
**Related test cases:** TC-018

## Summary
Monday allows two labels with the same name to coexist independently. Pipeline blocks renaming a label to an existing name with an inline validation message.

## Monday behaviour
Renaming a label to an existing name (L10 duplicated in the capacity stress test) is accepted; two independent labels with identical names coexist with separate IDs (14 and 15).

## Pipeline behaviour
Renaming L36 to the existing name L35 and clicking Apply is blocked with the inline message "Labels must be unique and nonempty." The editor retains the draft; Escape discards it.

## Reproduction steps
1. Open Edit Labels.
2. Rename any label to the exact name of another label.
3. Click Apply.

## Expected result (Monday reference)
The duplicate name is accepted and both labels coexist.

## Actual Pipeline result
Save blocked with the uniqueness validation message.

## Notes for future review
Pipeline enforces uniqueness per column. Monday treats label names as non-unique display strings.
