# D-009 — Editor structural affordances differ (reorder controls, Default Label lock, helper texts)

**Category:** Visual / Editor structure
**Related states:** S06 (editor opened)
**Related test cases:** TC-008, TC-009, TC-010

## Summary
Pipeline's Edit Labels editor includes keyboard reorder handles, Move up/Move down menu items, an editor-level helper text, and a partially locked Default Label row; Monday's editor has none of these affordances.

## Monday behaviour
Editor rows are colour swatch + text field + "..." menu (Add label description / Deactivate label / Delete label). No reorder handles or move items. No helper text. Default Label row fully locked. Colour changes save immediately (per live observation).

## Pipeline behaviour
Editor rows add a drag/keyboard reorder handle ("Reorder label N; use Up or Down arrow", Help "Drag to reorder; use arrow keys to move") and the options menu adds "Move up" / "Move down". A helper text line reads "Existing label colors save immediately. Apply saves other edits; Escape discards unapplied edits." Default Label row: colour swatch disabled, name editable, options menu present.

## Reproduction steps
1. Open Edit Labels.
2. Inspect a label row's left edge (reorder handle), options menu items, and the editor helper text.

## Expected result (Monday reference)
Row = swatch + text + options menu only; no reorder affordances; no helper text; Default Label fully locked.

## Actual Pipeline result
Extra reorder handle + Move up/Move down items; helper text present; Default Label row partially locked.
