# D-006 — Default Label row lock scope differs in the editor

**Category:** Visual / Interaction affordance
**Related states:** S06 (editor opened)
**Related test cases:** TC-008

## Summary
Monday locks the entire Default Label row (no options menu, no editing). Pipeline disables only the colour swatch of the Default Label row while keeping its name editable and its options menu present.

## Monday behaviour
The grey "Default Label" row has no "..." options menu at all; the row is locked from interaction.

## Pipeline behaviour
The Default Label row's colour swatch is disabled (greyed out), but the name text field remains editable and the "..." options menu is present (Add label description / Deactivate label / Move up / Move down / Delete label).

## Reproduction steps
1. Open Edit Labels.
2. Locate the Default Label row.
3. Compare available controls.

## Expected result (Monday reference)
The Default Label row is fully locked (no menu, no editing).

## Actual Pipeline result
Only the colour swatch is disabled; name editing and the options menu remain available.

Pipeline allows customizing the default label more than Monday. Deletion of the Default Label row appeared blocked in both products' menus.
