# D-007 — Dropdown helper text and (selected) marker present on Pipeline, absent on Monday

**Category:** Visual / Informational affordance
**Related states:** S03 (dropdown open, empty), S05 (dropdown open with existing value)
**Related test cases:** TC-002, TC-006

## Summary
Pipeline's Status cell dropdown shows a helper text line at the top and marks the current value with "(selected)" in the accessibility tree; Monday shows neither.

## Monday behaviour
The dropdown opens directly with the label options and "Edit Labels" footer; no helper text is rendered. The grey clear option has no "(selected)" marker in the AX tree.

## Pipeline behaviour
The dropdown opens with the helper text "Choose a status to save immediately. Escape closes without changing it." above the options and "Edit Labels" footer. The AX list marks the current value as "(selected)" (Monday instead marked the grey Empty option "(selected)" when no value was set).

## Reproduction steps
1. Click a Status cell to open the dropdown.
2. Compare the top-of-dropdown content and the AX list markers.

## Expected result (Monday reference)
No helper text; the empty/clear option is the default (selected) value.

## Actual Pipeline result
Helper text is shown; the current value carries the "(selected)" marker.

Functional parity is high; this is an informational affordance difference. The different (selected) semantics matter for accessibility-driven comparisons.
