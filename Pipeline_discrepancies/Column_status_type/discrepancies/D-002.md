# D-002 — Empty label text validation differs (Pipeline blocks, Monday saves)

**Category:** Functional / Validation
**Related states:** S13 (empty-text label editing), S14 (validation/error)
**Related test cases:** TC-016, TC-017

## Summary
Monday saves a Status label with empty text and no validation message. Pipeline blocks the save with an inline validation message and keeps the draft.

## Monday behaviour
"+ New label" left with empty text and committed via Apply produces a textless blue chip in the dropdown. No error is shown at any point; the empty label persists.

## Pipeline behaviour
Clearing a label name and clicking Apply is blocked with the inline message "Labels must be unique and nonempty. Your label draft is kept." plus a Dismiss affordance. A native "Please fill out this field." bubble also appears. Escape discards the draft.

## Reproduction steps
1. Open Edit Labels.
2. Add a new label and leave the name empty.
3. Click Apply.

## Expected result (Monday reference)
The empty label is saved silently and appears as a textless chip.

## Actual Pipeline result
Save blocked with an inline validation message; the draft is retained until dismissed or discarded.

## Notes for future review
Pipeline's validation is stricter than Monday's. Parity decision needed on whether empty labels should be allowed (Monday behaviour) or blocked (current Pipeline behaviour).
